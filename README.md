# IoT Platform Enterprise UI

A production-grade enterprise IoT platform UI built with React + Recharts.

## Quick Start

```bash
npm install
npm start
```

App runs at http://localhost:3000

## Folder Structure

```
src/
  index.js
  App.jsx
  context/ThemeContext.js
  components/index.jsx
  mock-data/index.js
  pages/
    Dashboard.jsx
    Connectivity.jsx
    Assets.jsx
    Alerts.jsx
    OtherPages.jsx
```

## Modules
Dashboard, Connectivity, Asset Management, Alerts & Analytics,
File Management, Reports, User Management, Organizations
